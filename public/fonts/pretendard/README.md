# Pretendard Variable

Version: 1.3.9. Official source: https://github.com/orioncactus/pretendard/tree/v1.3.9

The variable dynamic subset CSS and 92 WOFF2 subsets are served from this application's origin. Only URL paths in the upstream stylesheet were adjusted for local hosting; the font files are unmodified. `font-display: swap` and the original Unicode ranges are retained.
