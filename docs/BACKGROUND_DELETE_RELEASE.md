# 백그라운드 삭제와 파비콘 — 2026-10-04

## 변경

- 단일/선택 삭제가 R2 정리를 끝낼 때까지 요청과 모달을 묶어 두던 흐름을 변경했다. 확인 또는 TOTP 인증 후 모달을 닫고, 페이지와 독립적인 작업 저장소에서 요청을 처리한다. 사이트 내 화면 이동에도 결과 알림이 유지된다. 중복 진행 요청은 차단하고 실패/부분 실패는 전역 알림에 표시한다.
- 서버는 권한/CSRF/대상 검증 후 D1 상태를 DELETING으로 먼저 기록한다. 응답 시점부터 목록·새 다운로드·미리보기에서 제외되고, R2 정리는 waitUntil로 계속한다. Worker 종료나 저장소 오류 시 기존 15분 주기 정리 작업과 삭제 lease가 재시도한다. 저장소 정리가 확인되기 전에는 용량을 해제하지 않는다.
- 단일 삭제는 202/PENDING, 일괄 삭제는 파일별 PENDING 또는 실패를 반환한다. 이미 삭제된 대상은 기존 DELETED 응답을 유지한다. 알림은 목록에서 삭제됐다는 사실과 백그라운드 정리를 구분한다. 서버 접수 전 탭을 닫았을 때 요청 전달까지 보장하는 구조는 아니다.
- 기존 신뢰 기기 권한과 단일/선택 대상에 묶인 일회용 TOTP grant 정책은 유지한다. 이미 발급된 다운로드 URL/진행 중 수신 데이터의 회수는 보장하지 않는다.
- 메인 로고의 라임 원(#f1fd82), 검은 drop SVG 경로, 44:30 비율로 public/favicon.svg를 만들고 HTML icon 링크를 추가했다.
