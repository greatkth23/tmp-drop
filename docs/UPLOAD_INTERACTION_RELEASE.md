# 업로드 조작 및 묶음 이름 개선 — 2026-10-04

- 기본 보관 선택 상자는 높이 44px를 유지하고 SVG 화살표를 오른쪽에서 16px 안쪽에 둔다. 목록 안 선택 상자는 32px로 축소한다. 강제 색상 모드에서는 기본 선택 화살표를 사용한다.
- 업로드 페이지의 window에서 파일 드래그를 수신해 보이는 화면 전체에 흰 배경·점선·라임 SVG 안내를 표시한다. 놓으면 현재 목록에 추가하고 직접 시작하도록 한다. 텍스트/링크 드래그는 무시한다. 중첩 영역 진입/이탈 시 깜빡임을 방지하고 drop, 화면 이탈, Escape, blur, dragend에서 안내를 닫는다.
- 인증/연결/열린 대화상자 조건을 유지한다. 화면 전체가 드롭 영역이며 다른 페이지에서는 리스너를 제거한다.
- 묶음 제목과 ZIP 응답/클라이언트 파일명을 `대표 파일명 외 N개`로 통일한다. 대표는 화면 정렬과 같은 완료 시각 내림차순, ID 내림차순으로 결정한다. N은 대표를 제외한 수다. ZIP 이름은 Windows 예약 이름/금지 문자를 처리하고 UTF-8 255바이트 내에서 `.zip` 및 개수 접미사를 유지한다.
- 목록 보관 선택과 동작을 한 flex 영역에 묶어 12px 간격을 적용한다. 제거는 빨간 휴지통 SVG와 `제거`로 표시하며 접근성 이름에는 대상 파일과 목록/내역 범위를 유지한다.
- 상태 pill은 기존 토큰을 사용한다. 대기/취소 중립색, 전송/확정 중 라임, 완료 녹색, 인증/연결/취소 확인 황색, 실패 적색. 상태 텍스트를 함께 유지한다.
- `서버 확인 후 다른 기기에서 받을 수 있습니다.` 문구를 제거한다. 실제 확정 처리 및 진행 상태는 유지한다.
