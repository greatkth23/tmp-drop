# Personal Temporary Drop — 구현 백로그·검증 체크리스트

작성일: 2026-10-02 · 작업 상태: 전부 계획 단계. 구현·배포를 완료한 것으로 표시하지 않는다.

## 1. 작업 운영 규칙

우선순위 P0는 출시 차단 또는 선행 검증, P1은 v1 필수, P2는 후속 후보다. 아래 작업은 이슈로 옮길 수 있는 단위이며 공수는 `01-상세-구현-계획.md`의 단계 합계에 포함된다. 행마다 공수를 별도로 합산해 중복 계산하지 않는다.

각 이슈 완료 시 변경된 계약·테스트 결과·실제 환경·알려진 제한을 남긴다. 통과 증거 없이 ‘동작할 것’으로 닫지 않는다. 실패한 spike는 실패 조건과 선택한 대안을 기록한다.

**S04 실패 대안:** 안전하게 지원되는 조건부 복사를 확인할 때까지 Shortcut 공개 완료를 막는다. staging URL을 final URL로 그대로 사용하는 임시 수정은 하지 않는다.

## 9. 상태 경합·장애 주입 매트릭스

| 장애 위치 | 기대 수렴 | 관찰 항목 |
|---|---|---|
| 용량 예약 후 R2 create 실패 | FAILED→정리·예약 반환 | 이중 반환·영구 예약 없음 |
| R2 create 후 uploadId DB 저장 실패 | orphan MPU 정리 | listing·prefix 추적 |
| part 성공 후 DB 실패 | manifest 대조·복구 또는 안전 실패 | 손상된 파일 READY 없음 |
| part 응답 유실 | status 확인 후 안전 재시도 | 같은 part 중첩 쓰기 제한 |
| 오래된 part와 새 attempt 경합 | 확정 manifest 불일치 시 완료 차단 | D1 fencing만 믿지 않음 |
| complete 성공 후 DB 실패 | final HEAD로 READY 재조정 | 중복 file 없음 |
| 완료 API 두 번 호출 | 동일 결과 | completedAt·expiry 불변 |
| complete vs cancel | 선점 정책에 따른 한 결과 | 취소 성공 후 READY 금지 |
| source HEAD 후 staging 덮어쓰기 | if-match copy 실패 | 검증한 것과 다른 바이트 공개 금지 |
| final copy 후 응답·DB 유실 | 고정 final key·metadata로 복구 | 새로운 staging으로 재확정 금지 |
| staging 삭제 후 URL 재사용 | final 불변·staging 재청소 | URL 미회수 한계 기록 |
| R2 delete 성공 후 DB 실패 | 다음 delete no-op, DB 확정 | quota 1회 반환 |
| Cron 중복·lease 만료 | 재진입 안전 | 같은 객체·카운터 처리 반복 안전 |
| D1 전체 장애 | 인증/승인 fail closed | anonymous access·고아 무차별 삭제 없음 |

## 10. 브라우저·실기기 시험 기록 양식

각 시험마다 다음 항목을 채운다.

```text
Test ID:
일시 / 테스트한 commit:
Cloudflare 환경 / 플랜 / compatibility date:
기기 모델 / OS / 브라우저 또는 Shortcuts 버전:
네트워크(Wi-Fi/유선/이동통신) / 대략적인 대역폭:
원본 bytes / SHA-256:
part 크기 / 동시성:
시작·완료 시간 / 재시도 수 / CPU / peak memory 관측:
세션 만료 또는 장애 주입 시점:
다운로드 bytes / SHA-256:
예상 결과 / 실제 결과:
PASS / FAIL / 제한사항:
민감정보 제거한 로그·스크린샷 위치:
```

공개 CI에 파일 내용·token·PIN·S3 signed URL을 업로드하지 않는다. 대용량 fixture를 git에 넣지 않는다. 생성 seed·정확한 크기를 기록해 재현한다.

## 11. 출시 체크리스트

- [ ] S01–S08 결과와 지원 기기·크기 범위 확정.
- [ ] 세 인증 모델의 권한 분리 및 별도 download/admin 자격 검증.
- [ ] TOTP replay·rate limit·CSRF·cookie 설정 통과.
- [ ] 14분 시작→15분 만료→16 GiB 완료와 새 생성 거부 통과.
- [ ] 실제 다운로드 SHA-256이 원본과 일치.
- [ ] part/complete/cancel/revoke 경합에서 허용되지 않은 READY 없음.
- [ ] Shortcut는 완료 HEAD·조건부 복사 전 공개하지 않음.
- [ ] 완성 객체를 기존 PUT URL로 덮어쓸 수 없음.
- [ ] GET URL TTL이 파일·download session 잔여 시간 이하.
- [ ] 72시간 retention보다 먼저 fallback lifecycle이 삭제하지 않음.
- [ ] Cron 장애·중복·R2-D1 불일치 복구와 quota 회수 통과.
- [ ] 비인증 목록·원본 파일명·signed URL 누출 없음.
- [ ] private bucket, r2.dev public endpoint 비활성 확인.
- [ ] CSP·no-store·attachment·filename 인코딩 확인.
- [ ] 모바일·키보드·VoiceOver 핵심 흐름 통과.
- [ ] production과 staging 리소스·secret 분리.
- [ ] 요금·limits 최신 재확인, 예산 경고·운영 책임자 지정.
- [ ] bootstrap·Authenticator 분실·PIN 변경·DB 복원 문서 검토.
- [ ] rollback과 production smoke 수행.
