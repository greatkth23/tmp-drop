## 적용

- 정상 상태 안내와 선택 도구 모음을 흰 면으로 통합하고 구분선으로 위계를 만든다. 경고/오류 의미색은 유지한다.
- 일반 파일 행은 최소 80px, 아이콘 40px, 상하 여백 12px. 긴 이름은 자연스럽게 늘어나며 숨기지 않는다. 단일 파일과 묶음은 같은 열을 쓴다.
- V/^ SVG와 키보드 펼치기 버튼은 왼쪽, 체크박스는 오른쪽. DOM 순서도 시각 순서와 일치한다. 체크박스는 44px label 클릭 영역을 사용한다.
- 묶음 헤더 전체 클릭은 펼치기/접기이며 checkbox/link/button은 독립 동작한다. 단일 파일에는 펼치기 버튼이 없다.
- 묶음의 용량/가장 이른 만료/다운로드/삭제를 같은 행에 유지한다. 묶음 동작은 다른 항목의 선택 상태와 무관하게 해당 묶음을 대상으로 한다.
- 행 다운로드는 흰 보조 버튼. 펼친 자식만 약한 회색 면/들여쓰기로 구별한다. 모바일 크기와 만료는 함께 줄바꿈한다.
- 상단 탐색, 업로드/기기 행, 안내 섹션의 과도한 여백과 장식 면을 정리했다. 파일/기기 아이콘은 무배경으로 통일했다.
- 업로드 시작 영역을 목록 위로 이동하고 sticky top:0을 적용했다. 파일 수/총용량/시작 버튼을 스크롤 중에도 유지한다.
- 이미지 미리보기: PNG/JPG/GIF/WebP/AVIF, 최대 10MiB 후보, lazy/async 로딩, 실패 시 기존 아이콘. 큰 파일/지원하지 않는 형식은 다운로드 가능하며 미리보기만 생략한다.
- 업로드 대기 파일은 로컬 blob URL을 생성하고 컴포넌트 해제 시 revoke한다. 다운로드 목록은 인증된 `/api/files/:id/preview`를 사용한다.
- 미리보기 API는 PIN 세션, READY/만료, 크기 제한, 실제 raster signature를 검사한다. SVG/HTML을 표시하지 않는다. R2 원본은 private/no-store 및 nosniff/same-origin/sandbox 헤더로 응답한다. 서버 축소 이미지 생성은 하지 않는다.

## 검증

- `npm run check`: 타입 검사/Prettier/70 tests/production build 통과.
- 미리보기 회귀 검사: 정상 PNG byte 일치 및 MIME, 미인증/로그아웃 401, SVG 위장/크기 초과 415, 만료/삭제 404.
- 로컬 UI: 단일/묶음, 전체 선택 mixed state, 펼치기와 선택 독립 동작. 320/390px에서 페이지 가로 넘침 없음.
- 로컬에서 7개 파일 선택 후 업로드 완료. 목록 마지막 항목에 포커스를 이동한 상태에서도 시작 바 y=0, 버튼 y=66으로 유지됨을 확인.
- 추가 로컬 브라우저 접근은 권한 거절 후 중단했다. 우회하지 않았다.
- 운영에서 실제 PNG/JPG 미리보기 로딩, 단일/묶음 기본 높이 80px, 왼쪽 disclosure/오른쪽 선택 배치를 확인했다.
- 실제 사용자 파일 삭제는 수행하지 않았다. 기존 인증·선택 ZIP·삭제 API 회귀 검사를 유지했다.

## 한계

- 브라우저 320/390px 검증은 iPhone 실기기 확인을 대체하지 않는다.
- 최종 업로드 대기 상태의 blob 미리보기는 로컬 브라우저 추가 접근이 거절되어 직접 검증하지 못했다. 다운로드 목록의 서버 미리보기는 운영에서 확인했다.
- 썸네일용 이미지는 서버에서 리사이즈하지 않으므로 후보 원본(최대 10MiB)을 내려받는다. 화면상 크기만 40px로 표시한다.
